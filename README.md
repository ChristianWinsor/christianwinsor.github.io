# Christian Winsor - Portfolio

Personal portfolio website for Christian Winsor.

:globe_with_meridians: **Live site:** https://christianwinsor.github.io/

## About

This repository contains the source code for my personal portfolio website.

The site showcases my creative and technical work, including design, writing, projects, experiments, and other selected work.

## Built With

- React
- TypeScript
- Vite
- React Router
- CSS
- GitHub Pages

## Features

- Responsive design
- Project case studies
- Gallery
- Resume and experience
- Contact page
- Client-side routing
- Lazy-loaded routes
- Accessibility-focused navigation
- Reduced-motion support
- Responsive mobile navigation
